# v0.1.1 Reliability Implementation Plan

> **For agentic workers:** Execute each task with failing regression tests, a minimal fix, and a passing targeted test run. Use subagent-driven-development for independent work and review. The user authorized local commit and remote push after verification.

**Goal:** 修复已有命令与更新流程的可靠性问题，完成 v0.1.1 本地提交和远端推送。

**Architecture:** 保留 Click CLI、分析器和生成器的现有结构。三个 Python 配置读取入口共用 TOML 解析；JSON 输出直接写 stdout，诊断写 stderr；文本更新仅替换 marker 内部，JSON 合并优先保留已有值。

**Tech Stack:** Python >=3.10, Click, Rich, Jinja2, pytest, Ruff, Hatchling; Python 3.10 条件依赖 tomli。
